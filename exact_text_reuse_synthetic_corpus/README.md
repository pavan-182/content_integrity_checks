# Synthetic Exact Text Reuse Corpus

This folder contains synthetic JATS-style meeting abstracts for testing exact-text-reuse detection.

Cases:
1. Full abstract duplicate
2. Exact Methods-section reuse
3. Three uncommon Results sentences reused verbatim
4. Same-topic negative control written independently

All names, institutions, data, analyses, and results are fictional. These files are test fixtures only and must not be submitted, published, or represented as real research.
