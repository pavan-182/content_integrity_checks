# ASCO Integrity Pipeline Diagrams

Each diagram is stored as standalone Mermaid source so it can be opened and previewed directly in VS Code.

| Diagram | Renderable source | Focus |
|---|---|---|
| Workflow | [`diagrams/workflow.mmd`](diagrams/workflow.mmd) | Complete batch execution sequence |
| Architecture | [`diagrams/architecture.mmd`](diagrams/architecture.mmd) | Components, layers, dependencies, and external boundary |
| Data flow | [`diagrams/data_flow.mmd`](diagrams/data_flow.mmd) | Data contracts, transformations, and generated artifacts |
| Decision flow | [`diagrams/decision_flow.mmd`](diagrams/decision_flow.mmd) | Finding creation and exact risk precedence |

Open any `.mmd` file and use the installed Mermaid preview command. The files contain raw Mermaid syntax without Markdown code fences, so they also work with Mermaid CLI and compatible renderers.
